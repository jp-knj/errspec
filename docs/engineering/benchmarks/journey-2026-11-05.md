# Journey mutation comparison, 2026-11-05

This is a partial practical trial, not completion of the full KARTE acceptance
plan. It compares mutator 0.2.0 at
`025870640d46e93e97285d67e4c265074cf8b295` with errspec's scope-cache
implementation at `8279beb361839bbeb90bdcceca810435681885e2`.

Both ran on the same macOS ARM machine using Node 24.22.1, the same Vitest 5.0.3
runner package, the same unmodified journey/usecases sources and 146 baseline
tests. The project's own Vitest imports resolve to its existing 5.0.0 dependency.
Both used four mutation workers with weak mutation, arid exclusion and typechecking
disabled. errspec enabled session reuse, result caching and scope caching.
mutator used its ordinary snapshot-based reuse. Existing lockfiles were retained.

| Observation | mutator | errspec |
| --- | ---: | ---: |
| Candidate inventory | 778 | 818 |
| First run | 122.965 s | 243.461 s |
| Unchanged repeat | 0.124 s | 20.054 s |
| First-run mutant trials | 716 | 754 |
| Repeat mutant trials | 0 | 1 |
| Killed | 639 | 675 |
| Survived | 76 | 78 |
| NoCoverage | 62 | 62 |
| Timeout | 1 | 1 |
| Ignored | 0 | 2 |

These are one first run and one repeat per tool, not medians or a controlled
performance study. Their inventories and revalidation contracts differ. errspec
still runs the ordinary baseline on an unchanged repeat and refreshes the timeout;
mutator's repeat ran no dry-run files. No optimization is inferred or implemented
from these timings. In this observation errspec took longer, including on repeat.
The reference host process ended with status 1 even though both returned API reports
were complete and unchanged; that process status remains recorded separately from
the per-mutant verdicts.

Exact comparison converts the reference's UTF-16 ranges into UTF-8 offsets and
matches file, range, family, original text and raw replacement. It verifies both
original slices against the current source. It does not equate differently quoted
strings or otherwise normalize replacement syntax.

There were **582 exact common edits, with all 582 verdicts agreeing**. All source
slices matched. There were 236 errspec-only and 196 reference-only exact identities;
these include spelling differences and cannot be counted as additional bugs.
Neither survivor counts nor agreement establish that an actual product bug was
found. Manual assessment of useful gaps, noise and investigation costs, the Git
diff trial and the obel/agent-studio failure checks remain outstanding.

The aggregate artifact is [journey-2026-11-05.json](journey-2026-11-05.json).
Raw reports, snapshots and project sources are retained locally and are not
included in this repository. To repeat the exact comparison with native reports
or the benchmark wrappers' `{report, elapsedMs}` records:

```sh
node scripts/compare-mutation-reports.mjs \
  --root /path/to/project \
  --native /private/path/native-cold.json \
  --reference /private/path/reference-cold.json \
  --output /private/path/exact-comparison.json
```

The comparator rejects stale source slices, split Unicode ranges, duplicate exact
edits and paths outside the project. Unmatched syntax stays unmatched; Pending and
other different statuses remain visible differences. The comparison's executable
regressions are in `tests/mutator-comparison.test.mjs`.
